PROJECT IQBAL
Human × AI Exam Academy
=======================

REQUIRED FILES
--------------
1. index.html
2. style.css
3. data.js
4. script.js

All four files must be inside the same folder.

HOW TO RUN
----------
1. Create a folder named PROJECT-IQBAL.
2. Save each code block using the exact filename above.
3. Open index.html in a modern browser.
4. Choose an exam.
5. Open Subjects to explore available study material.
6. Open Practice to attempt questions.
7. Use My Notes to save personal notes.
8. Open Progress to view saved practice history.
9. Export Backup regularly to preserve your data.

IMPORTANT LIMITATIONS
--------------------
- This version is a local, browser-based application.
- Data is saved in the browser's localStorage.
- Clearing browser data may erase saved notes and progress.
- Export Backup before changing devices or browsers.
- There is no online account or cloud synchronization.
- The embedded dataset is a starter collection, not a complete
  verified syllabus or a complete archive of previous-year questions.
- Questions are labelled as practice questions unless verified PYQ
  information is explicitly available.
- Always check official recruitment notifications for the current
  syllabus, exam pattern, dates and eligibility rules.
